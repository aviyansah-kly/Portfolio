06 / COMMON QUESTIONS

Before we get started.

Answers to a few common developer questions.

Can we start with just a show unit?

Yes. intlife provides smart living experiences for developer show units and sales galleries. The scope can be discussed based on your development.

Which smart home features are available?

Options include smart lighting, air-conditioning, door locks, security and app control. The final package depends on device compatibility and project requirements.

When should we involve intlife?

Ideally during planning, so device selection, cabling and installation can be considered early. You can also discuss an ongoing development.
