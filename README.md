# Avi Yansah Portfolio

Personal portfolio for Avi Yansah — Product Designer & Web Creator.

## Stack

- Next.js
- TypeScript
- GSAP
- Lenis
- Custom CSS

## Direction

Inspired by high-end independent designer portfolios: oversized typography, smooth interactions, strong project storytelling, and conversion-focused presentation.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000


## Cloudflare deployment

This project uses Next.js static export and Cloudflare Workers Static Assets.

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Output directory: `./out`
